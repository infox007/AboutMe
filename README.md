- **企业级信息化项目交付** — 负责需求梳理、进度推进、问题处置与上线培训，对接研发、设计与客户多方

## 代表项目

### 数据看板 / Data Dashboard

多源 CSV 数据接入 → 清洗聚合 → 可视化呈现的完整链路。带后台管理界面，非技术同事也能自己上传数据并刷新图表。
`Python` `Flask` `ECharts` · 

### 数据分析 Agent「小张」

用 LangChain 把大模型接进看板体系，用户直接用自然语言提问，Agent 自动完成取数、计算与结论整理，省掉"提需求 — 等排期"的往返。
`LangChain` `DeepSeek` `Agent` · 

### 招聘信息聚合与匹配工具

定时抓取职位信息，按岗位关键词、城市、薪资区间过滤，并与个人简历做匹配打分排序，把每天找岗位的时间从一小时压到几分钟。
`Python` `爬虫` `匹配算法` ·
